# Changelog

Все значимые изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается семантического версионирования.

## [1.2.0] - 2026-08-26

### Changed

- **Приложение похудело в 5,7 раза: сборка 5,61 → 0,98 МБ, CSS 230 → 17 КБ.** Веб-шрифт иконок
  Tabler занимал 4,42 МБ в трёх форматах и 5807 правил CSS ради 34 иконок — почти 80% веса. Теперь
  иконки — инлайновые SVG, собираются командой `node scripts/build-icons.mjs` в
  `components/icon-paths.ts`; в зависимостях приложения шрифта больше нет.
- **Архивные объекты больше не мешают.** Статус `archived` записывался, но ни на что не влиял:
  архивное висело в общем списке, попадало в «Требует внимания» и генерировало напоминания. Теперь
  в реестре есть раздел «Архив», а сам архив молчит — и в сводке, и в уведомлениях. В архиве
  объект показывает спокойное «в архиве» вместо красного «просрочено».
- Кнопка настроек — иконка вместо жёстко зашитой буквы «А», которая для другого человека ничего
  не значила.
- Убран текст «Проверьте, что сервер запущен» — сервера нет с 1.0.

### Added

- **Дата последней резервной копии и напоминание о ней.** Факт экспорта нигде не сохранялся, и
  человек мог год не делать копию, не зная об этом. Дата видна в настройках, а если копии не было
  больше 30 дней, «Сегодня» спокойно об этом напомнит.
- **Удаление решений, критериев и вариантов, правка «в чём вопрос».** Ошибочно созданное решение
  раньше нельзя было убрать, а контекст задавался только при создании.
- **Правка и удаление домашних задач** — название, срок и исполнителя можно поменять после создания.
- **Экран ошибки вместо белого листа.** При отказе хранилища (приватный режим, повреждённая база)
  приложение показывает, что случилось, и предлагает перезапуск — раньше оно молча зависало на
  «Загрузка…» или падало целиком.

### Tests

94: 35 в `packages/domain` и 59 в `apps/app` (архив, напоминание о копии, правка задач, подача
статуса).

## [1.1.0] - 2026-08-22

Три места, где домен умел больше, чем интерфейс, — доведены до конца.

### Added

- **Поля документа в реестре.** У каждого типа объекта свой набор полей (серия и номер у документа,
  госномер и VIN у транспорта, сумма и ставка у обязательства) — каталог `object-fields.ts` в домене.
  Раньше `data` только отображалось, а записать номер паспорта было негде.
- **Чувствительность задаётся вручную** при создании и правке, с разумным значением по умолчанию для
  типа (медкарта — повышенная, документы и страховки — чувствительная). Маскирование значений в
  карточке существовало и раньше, но включить его было нечем.
- **«Действует с»** редактируется, а не только показывается.
- **Завершение решения и журнал исходов.** Вариант выбирается прямо во «Взвешенном итоге» — решение
  фиксируется с датой; записывается, чего вы от него ждали, а потом что вышло на самом деле. Есть
  возврат в черновик с подтверждением. Доменные правила: `decideDecision`, `recordOutcome`,
  `reopenDecision` — исход нельзя записать черновику, а выбрать несуществующий вариант нельзя вовсе.
- **Сроки у домашних задач.** Дата у задачи, подсветка просроченного, сортировка «ближайшее сверху»
  в «Сегодня» и напоминание в день срока (у задач один порог, а не шкала документов).

### Changed

- Заголовок «Сегодня» учитывает просроченные задачи, а не только документы: раньше при просроченной
  задаче он всё равно сообщал «всё под контролем».
- Подписи полей в карточке объекта человеческие вместо технических ключей.

### Tests

82: 35 в `packages/domain` (жизненный цикл решения) и 47 в `apps/app` (хранение полей и
чувствительности, напоминания о задачах).

## [1.0.0] - 2026-08-21

Смена архитектуры: приложение работает только на устройстве. Сервера, аккаунтов и сетевого API
больше нет — см. [ADR 0006](docs/adr/0006-local-only.md).

### Changed

- **Хранилище — IndexedDB на устройстве** вместо PostgreSQL и кэшей в localStorage. Новый слой
  `apps/app/src/lib/store`: объекты реестра, решения, дом, задачи, прогресс плейбуков, вложения.
  Содержимое файлов лежит там же, `ArrayBuffer`-ами (структурное клонирование ведёт себя одинаково
  во всех WebView, в отличие от Blob).
- **Вложения хранятся на устройстве**, а не на серверном диске. Валидация по магическим байтам
  сохранена, лимит поднят с 10 до 25 МБ. Шифрования нет и не может быть без пароля пользователя —
  это прямо сказано в [SECURITY.md](docs/SECURITY.md).
- **«Дом» стал личным**: люди дома (справочник для назначения задач) и общие задачи с исполнителем.
  Приглашений по e-mail, ролевого доступа и журнала аудита нет — без сервера разделять данные не с кем.
- **Напоминания** планируются системой: на Android приходят и при закрытом приложении
  (`@capacitor/local-notifications`), на десктопе — пока окно запущено.
- **`apps/web` переименован в `apps/app`** (`@life-os/app`): это приложение, а не сайт.
- **Релиз — два артефакта**: `.exe`/`.msi` и `.apk`. Веб-архива и Docker-образов больше нет.
- **APK подписывается релизным ключом** вместо debug. Обновление поверх версий до 1.0 невозможно —
  Android не меняет подпись пакета, старую версию нужно удалить.
- Версия проставляется во все места одной командой `node scripts/set-version.mjs X.Y.Z`; раньше
  корень жил в `0.0.0`, а оболочки в `0.9.x`.
- Русские числительные склоняются (`1 объект`, `2 человека`, `5 задач`) вместо «1 объектов».

### Added

- **Резервная копия** — экспорт и импорт всех данных одним файлом, включая вложения (Настройки →
  Резервная копия). Единственный способ перенести данные и единственная страховка от их потери.
- **Удаление всех данных** с подтверждением.
- Одноразовый перенос данных прежнего локального режима из localStorage в IndexedDB.
- Системный авто-бэкап Android отключён (`allowBackup=false`, `data_extraction_rules`), чтобы данные
  не уезжали в облако вопреки обещанию.

### Removed

- `apps/api` (NestJS), `infra/` (PostgreSQL, Docker, Caddy, nginx), workflow `deploy.yml` и сборка
  образов в GHCR.
- Вход, регистрация, MFA (TOTP), passkeys (WebAuthn), сессии, сброс пароля по e-mail.
- ИИ-подсказки и все провайдеры: ключи жили на сервере, проксировать их больше негде.
- Совместный семейный доступ и синхронизация между устройствами.
- PWA-обвязка (service worker, манифест): веб как продукт больше не существует, а в оболочках SW
  только кэширует устаревший бандл.
- Из домена: схемы аккаунтов и ИИ, журнал аудита, серверная RBAC-матрица, share-гранты, заглушка HLC.
- Документы `docs/API.md`, `docs/RBAC.md`, `docs/OPERATIONS.md` — описывали серверную часть.

### Tests

72 теста: 31 в `packages/domain` (правила) и 41 в `apps/app` (хранилище, вложения, резервные копии,
напоминания, миграция, экран реестра). Тесты хранилища идут через настоящее API IndexedDB
(`fake-indexeddb`), а не через моки.

## [0.9.4] - 2026-08-18

Последняя клиент-серверная версия. Ниже — накопленные изменения до перехода на локальную
архитектуру; всё, что касается сервера, аккаунтов и ИИ, в 1.0 удалено.

### Added

- **Сброс пароля по e-mail**: экран «Забыли пароль?» → письмо со ссылкой (одноразовый токен, TTL 1ч,
  хранится только хэш) → экран установки нового пароля (`?reset=<token>`). После смены пароля все
  сессии отзываются. Универсальный SMTP (nodemailer) через `SMTP_*`; без настройки письма не уходят
  (ссылка пишется в лог). Эндпоинты `POST /auth/password/forgot|reset` (публичные, throttled, без
  раскрытия существования e-mail). API +3 теста. Проверено E2E: forgot → reset → вход новым паролем.
- **Политика конфиденциальности** (`docs/PRIVACY.md`) + ссылка в настройках.
- **Продакшен-конфигурация сервера**: нативные сборки по умолчанию смотрят на прод-адрес
  (repo variable `API_BASE_URL`); `docker-compose.prod` пробрасывает `APP_URL`, `ALLOWED_ORIGINS`,
  `SMTP_*`. `.env.example` дополнен.
- **Единый дизайн форм и диалогов**: общий базовый стиль всех полей (input/select/textarea) с
  одинаковыми границами, фоном, скруглением и состоянием фокуса (шалфейная рамка) — ничто больше не
  падает в браузерный дефолт. Клавиатурный фокус (`:focus-visible`) для кнопок/карточек. Нативные
  `window.prompt`/`confirm` заменены внутренними диалогами в стиле приложения (переиспользуемый
  `Dialog`: `PromptDialog` для «Новое решение», `ConfirmDialog` для удаления объекта).
- **Больше провайдеров ИИ** (#7): помимо Claude — OpenAI (GPT), DeepSeek, Google Gemini и «Другой»
  (любой OpenAI-совместимый: Groq, Mistral, OpenRouter, локальный Ollama). Выбор в настройках; ключ
  задаётся на сервере (`OPENAI_API_KEY`, `DEEPSEEK_API_KEY`, `GEMINI_API_KEY`, `AI_CUSTOM_*`). Без
  ключа — Noop, приложение работает как обычно. Провайдеры: OpenAI-совместимый адаптер + Gemini-адаптер.
- **Родственные статусы в Доме и приглашение по e-mail** (#6): у участника теперь есть статус (муж,
  жена, партнёр, ребёнок, родитель, тёща/свекровь, зять и др.) отдельно от роли-прав. Реального
  человека добавляют по e-mail (`POST /households/:id/members/invite`) — если он зарегистрирован,
  создаётся членство с ролью по умолчанию из статуса. Панель добавления переписана (пригласить по
  почте / добавить без аккаунта). Миграция `0002` (колонка `relationship`).
- **Десктоп запоминает окно** (#1): `tauri-plugin-window-state` — размер, позиция и развёрнутость
  восстанавливаются между запусками.

### Security

- **Убран общий секрет по умолчанию** (#8): `JWT_SECRET`/`ENCRYPTION_KEY` больше не завязаны на
  публичный дефолт из исходников (иначе токены можно было бы подделать на любой чужой установке).
  Если стойкий секрет не задан, API генерирует случайный и хранит его в таблице `app_secrets`
  (миграция `0003`) — уникально на установку, стабильно между перезапусками, без ручной настройки.

### Fixed

- **Данные не сохранялись / вылеты из аккаунта** (#3, #4): API теперь применяет миграции автоматически
  при старте (идемпотентно) — таблицы всегда существуют. `docker-compose.prod` открывает порт API
  наружу (десктоп/телефон достают его) и задаёт стабильные `JWT_SECRET`/`ENCRYPTION_KEY`. Проверено:
  регистрация → создание данных → перезапуск API → вход работает, данные на месте.

  API: +6 тестов (upsert decision/household-task/progress).

  - **Desktop (Tauri, `apps/desktop`)**: Rust-оболочка + WebView2, сборка NSIS `.exe` + WiX `.msi`,
    брендовые иконки. Rust-код полностью компилируется локально; инсталлятор собирает CI (MSVC).
  - **Mobile (Capacitor, `apps/mobile`)**: нативный Android-проект, сборка `.apk` из общего `dist`.
  - **Конфигурируемый адрес API**: `VITE_API_BASE` при сборке + рантайм-переопределение (поле
    «Адрес сервера» на экране входа, `los-api-base`) — для self-hosted бэкенда. Web/PWA без изменений
    (относительный `/api/v1`).
  - **CI релиза** (`release.yml`): на тег `v*` собираются и прикрепляются к GitHub Release
    инсталляторы `.exe`/`.msi` (windows-latest, MSVC) и `.apk` (ubuntu-latest, JDK 17 + Android SDK).

- **Автообновление нативных приложений** (веб уже обновлялся через service worker):
  - **Desktop (Tauri): тихое авто-обновление** из GitHub Releases — проверка `latest.json`, проверка
    подписи (ed25519, публичный ключ в конфиге), скачивание нового `-setup.exe` и перезапуск.
    Плагины `tauri-plugin-updater`/`-process`; артефакты подписываются в CI (секрет
    `TAURI_SIGNING_PRIVATE_KEY`, пароль ключа пустой); генерируется и публикуется `latest.json`.
  - **Android (Capacitor): проверка + установка в один тап** — приложение читает `mobile-update.json`
    и предлагает баннером установить свежий APK (тихая замена пакета без стора Android'ом не разрешена).
  - Клиентский модуль `native-update.ts` (детект Tauri/Capacitor), баннер обновления в `App`.

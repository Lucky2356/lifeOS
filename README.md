# Life OS

Персональная и семейная «операционная система для жизни»: единый реестр данных о жизни человека,
который в спокойном режиме держит порядок, а в кризис подсказывает конкретные следующие шаги.

> **Ключевой принцип:** ИИ — опциональный ассистент поверх системы, а не её фундамент.
> Любая функция работает и без ИИ. ИИ можно выключить глобально и по модулям без деградации core-функций.

## Статус

✅ **Рабочий продукт.** Все 5 модулей реализованы, есть релизы для веба, ПК (Windows) и Android с
автообновлением. Данные хранятся в PostgreSQL (или локально на устройстве в режиме без аккаунта).

## Установка (для пользователей)

Скачайте на странице [релизов](https://github.com/Lucky2356/lifeOS/releases/latest):

- **ПК (Windows):** `Life OS_*_x64-setup.exe` — установщик (обновляется сам).
- **Android:** `life-os-*.apk` — включите установку из неизвестных источников.
- **Веб:** откройте свой развёрнутый экземпляр в браузере и «Установить приложение».

**Пользоваться можно сразу** — на экране входа нажмите «Продолжить без аккаунта»: данные останутся на
устройстве, сервер не нужен. Аккаунт создаётся позже — для входа с других устройств, синхронизации,
семейного доступа («Дом») и двухфакторной защиты.

## Модули

| Модуль                    | Роль                                                                                    | Приоритет разработки |
| ------------------------- | --------------------------------------------------------------------------------------- | -------------------- |
| **Life Ledger**           | Ядро: реестр «объектов жизни» (документы, вещи, подписки, страховки, здоровье, финансы) | 1                    |
| **Household OS**          | Тот же реестр на семью/дом: роли, права, общие задачи и расходы, синхронизация          | 2                    |
| **Decision Companion**    | Сквозной фреймворк принятия решений + журнал исходов                                    | 3                    |
| **Bureaucracy Autopilot** | Региональные пошаговые гиды по бюрократии (через content packs)                         | 4                    |
| **Crisis Navigator**      | Плейбуки тяжёлых ситуаций, привязанные к данным Ledger                                  | 5                    |

## Стек

- **Клиент:** React 19 + Vite (PWA), TypeScript strict, дизайн-система «Calm Sanctuary» (CSS-токены,
  две темы), общий доменный слой offline-first (кэш + очередь мутаций, LWW).
- **Нативные оболочки:** Tauri (ПК, `.exe`/`.msi`) и Capacitor (Android, `.apk`) поверх того же PWA.
- **Бэкенд:** NestJS 11, PostgreSQL 17 + Drizzle ORM, аутентификация argon2id + TOTP MFA + JWT.
- **Монорепо:** pnpm + Turborepo; общий пакет `@life-os/domain` (Zod-схемы и правила).
- **Развёртывание:** Docker Compose (self-host); GitHub Actions собирает образы и инсталляторы.

## CI и безопасность

Каждый push/PR прогоняет блокирующие гейты (`.github/workflows/`): lint + format, типы, тесты,
валидация content-pack, **SCA** (аудит зависимостей), **secret scanning** (gitleaks), **SAST** (CodeQL).
Локально: `pnpm lint && pnpm format:check && pnpm typecheck && pnpm test && pnpm validate:content`.

## Быстрый старт (локально)

Требуется Node ≥ 22 и pnpm. Для персистентной БД — Docker.

```bash
pnpm install

# Вариант A — без БД (zero-config, in-memory):
pnpm --filter @life-os/api dev            # API на http://localhost:3011
pnpm --filter @life-os/web dev            # Web на http://localhost:5173

# Вариант B — с PostgreSQL:
docker compose -f infra/docker/docker-compose.yml up -d
cp apps/api/.env.example apps/api/.env    # DATABASE_URL указывает на порт 5433
pnpm --filter @life-os/api dev            # миграции применяются автоматически при старте
```

Тесты: `pnpm -r test`. Сборка всего: `pnpm build`.

## Self-host (весь стек + синхронизация между устройствами)

```bash
echo "DOMAIN=lifeos.example.com" >> infra/docker/.env   # публичный домен, указывающий на сервер
docker compose -f infra/docker/docker-compose.prod.yml up -d --build
# Приложение по HTTPS: https://lifeos.example.com (Caddy сам получает сертификат Let's Encrypt)
```

Секреты и миграции применяются автоматически (уникальный секрет на установку хранится в БД). Caddy
терминирует TLS и служит единой точкой входа — `api`/`web` наружу не открыты. Чтобы телефон и ПК
синхронизировались, оба должны обращаться к одному API: на устройстве укажите `https://<DOMAIN>/api/v1`
в поле «Адрес сервера» на экране входа. Детали (TLS, заголовки, обновление с существующими данными) —
в [docs/OPERATIONS.md](docs/OPERATIONS.md).

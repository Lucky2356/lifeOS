# Life OS

Личная «операционная система для жизни»: единый реестр документов, вещей и обязательств, который в
спокойном режиме держит порядок и напоминает о сроках, а в трудной ситуации подсказывает конкретные
следующие шаги.

> **Всё живёт на вашем устройстве.** Нет сервера, нет аккаунта, нет облака — данные физически некуда
> отправить. Единственный выход в сеть — проверка новой версии приложения.

## Статус

✅ **1.0 — рабочий продукт.** Пять модулей, установщики для Windows и Android с автообновлением.
Данные — в локальном хранилище устройства; перенос и страховка — экспорт резервной копии в файл.

## Установка

Скачайте на странице [релизов](https://github.com/Lucky2356/lifeOS/releases/latest):

- **Android:** `life-os-*.apk` — потребуется разрешить установку из неизвестных источников.
- **Windows:** `Life OS_*_x64-setup.exe` — установщик, дальше обновляется сам.

Приложение открывается сразу: ни регистрации, ни пароля. Доступ к данным разграничивает учётная
запись вашего устройства.

> ⚠️ **Сделайте резервную копию.** Настройки → «Сохранить копию всех данных». Единственная копия
> данных лежит на устройстве: удаление приложения, сброс или потеря устройства означают потерю всего.

> Если у вас была установлена версия до 1.0 (Android), её нужно удалить перед установкой: начиная с
> 1.0 APK подписан релизным ключом, и Android не обновляет пакет с другой подписью.

## Модули

| Модуль                    | Что делает                                                                                                                                                       |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Life Ledger**           | Реестр «объектов жизни»: документы, вещи с гарантией, подписки, страховки, здоровье, финансовые обязательства. Сроки и напоминания, сканы и PDF рядом с записью. |
| **Household OS**          | Домашние дела и люди, которых они касаются: задачи с исполнителем, справочник семьи.                                                                             |
| **Decision Companion**    | Взвешенная матрица критериев и вариантов + журнал исходов: чего ждали и что вышло.                                                                               |
| **Bureaucracy Autopilot** | Пошаговые гиды по бюрократии из регионального контент-пака.                                                                                                      |
| **Crisis Navigator**      | Плейбуки трудных ситуаций (потеря работы, смерть близкого, переезд), связанные с реестром.                                                                       |

## Стек

- **Приложение:** React 19 + Vite 7, TypeScript strict, дизайн-система «Calm Sanctuary» (две темы).
- **Хранилище:** IndexedDB на устройстве, включая содержимое вложений.
- **Оболочки:** Tauri 2 (Windows `.exe`/`.msi`) и Capacitor 6 (Android `.apk`) поверх одной сборки.
- **Монорепо:** pnpm + Turborepo; пакет `@life-os/domain` — Zod-схемы и предметные правила.

## Разработка

Требуется Node ≥ 22 и pnpm. Базы данных и Docker не нужны.

```bash
pnpm install
pnpm --filter @life-os/app dev     # http://localhost:5173
```

Гейты качества — те же, что в CI:

```bash
pnpm build && pnpm lint && pnpm format:check && pnpm typecheck && pnpm test && pnpm validate:content
```

Каждый push/PR дополнительно прогоняет аудит зависимостей (SCA), поиск секретов (gitleaks) и SAST
(CodeQL).

Сборка установщиков и выпуск релиза — [docs/RELEASES.md](docs/RELEASES.md).

## Резервное копирование

Экспорт (Настройки → «Сохранить копию всех данных») складывает всё — записи и приложенные файлы — в
один JSON. Импорт («Восстановить из файла») проверяет файл и заменяет содержимое приложения целиком.

Куда попадает файл: на Windows — папка «Загрузки», на Android — системное «Поделиться» (выбираете
сами). Файл не зашифрован, поэтому храните его так же, как храните документы.

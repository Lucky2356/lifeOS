# Life OS — Дизайн-система и UX (Фаза 2)

> Направление: **«Calm Sanctuary»**. Дизайн — часть функции продукта: он должен снижать тревогу
> пользователя, а не эксплуатировать внимание. Черновик Фазы 2, ожидает утверждения.

## 1. Принципы (calm technology)

- **Спокойствие по умолчанию.** Никаких стриков, бесконечных лент, кричащих счётчиков непрочитанного,
  манипулятивных механик вовлечения. «Сегодня» — спокойная сводка, а не firehose.
- **Меньше, но яснее.** Много воздуха, крупные цели нажатия, одна ясная задача на экран.
- **Тревога дозирована.** Красный (Brick) — только для настоящей срочности (просрочка), и даже он
  приглушён. Приближение дедлайна — тёплый янтарь, а не паника.
- **Данные — это спокойствие.** Пользователь всегда видит, что система «держит» его дела под контролем.

## 2. Палитра и темы

Продукт поставляется с **двумя равноправными темами и переключателем** (уважает `prefers-color-scheme`):

- **Light — «Calm Sanctuary»**: тёплая бумага, повышенный контраст текста для читаемости.
- **Dark — «Quiet Dark»**: тёплый почти-чёрный холст, богатые приглушённые акценты.

Токены реализуются в `packages/ui` как CSS-переменные, тема переключается атрибутом `data-theme`.

## 3. Типографика

- **Заголовки и «голос» системы:** Fraunces (гуманистический serif) — тепло и доверие.
- **Интерфейс, данные, формы:** Inter — читаемость при любом масштабе.
- Масштаб: display 30 / h1 24 / h2 18 / h3 16 / body 15–16 (line-height 1.7) / caption 13 / micro 12.
- Только два начертания (400/500). Sentence case везде, без Title Case и CAPS (кроме микро-меток трекинга).

## 4. Форма и материал

- Скругления: карточки 12–16px, контролы 10px, пилюли 999px.
- Границы: hairline `0.5px var(--line)`; тени — минимальные и мягкие, только функциональные (фокус).
- Иконки: единый outline-набор (Tabler-подобный), 18–20px inline.

## 5. Ключевой паттерн — ничего не происходит само

Приложение не делает за пользователя шагов, которых он не просил, и не прячет последствий.
Необратимые действия (удалить объект, стереть все данные, восстановить из копии) идут через
внутренний диалог, который называет последствие прямо: «текущие данные будут заменены»,
«восстановить можно только из резервной копии». Никаких тёмных паттернов, срочности и
предвыбранных опасных вариантов.

Ранее в этом разделе описывалась маркировка ИИ-подсказок фиолетовым блоком; ИИ-слоя больше нет
([ADR 0006](adr/0006-local-only.md)).

## 6. Информационная архитектура

Продукт ощущается как **одно** приложение, а не пять. Единая левая навигация (desktop/web) /
нижняя таб-панель (mobile):

```
Сегодня        — спокойная сводка: ближайшие дедлайны, задачи дома, активные плейбуки
Реестр         — Life Ledger: все объекты жизни, фильтры по типам
Дом            — Household OS: люди дома и общие задачи с исполнителем
Решения        — Decision Companion (сквозной, но имеет и свой раздел-журнал)
Навигатор      — Crisis Navigator + Bureaucracy Autopilot (плейбуки и гиды)
  └ Настройки  — уведомления, резервная копия (экспорт/импорт), удаление всех данных
```

- **Decision Companion** доступен ещё и как сквозное действие «Принять решение» из любого объекта/шага.
- **Bureaucracy Autopilot** живёт внутри «Навигатора» и встраивается шагами в плейбуки Crisis.
- Глобальные: поиск по всему реестру, быстрое «+ добавить объект».

## 7. Доступность (обязательное НФТ)

- Контраст WCAG AA как минимум; проверяется в CI (линт токенов/компонентов).
- Полная навигация с клавиатуры, видимый фокус, корректные ARIA-роли, поддержка скринридеров.
- Масштабируемый текст (rem), уважение `prefers-reduced-motion` и `prefers-color-scheme`.
- Формы: явные подписи, понятные ошибки (что случилось + что сделать), без «Error:».

## 8. Тон текста (UX writing)

- Тёплый, ясный, без канцелярита и без паники. «Паспорт истекает через 72 дня» — факт + спокойное
  предложение действия, а не «ВНИМАНИЕ! СРОЧНО!».
- Sentence case, активный залог, глагол вперёд в кнопках («Открыть плейбук», «Добавить объект»).

## 9. Ключевые экраны (спроектированы и согласованы до вёрстки)

Все шесть ключевых экранов отрисованы как макеты и согласованы:

1. **Сегодня** — спокойная сводка «требует внимания» без тёмных паттернов.
2. **Реестр (Life Ledger)** — сетка объектов, фильтры по типам, поиск, «+ добавить».
3. **Карточка объекта** — поля (чувствительные замаскированы), вложения, напоминания-правила, история.
4. **Плейбук (Crisis Navigator)** — прогресс, шаги с чек-листом, привязка нужных документов к реестру
   («есть у вас» / «оформить»), встроенные бюрократические гиды.
5. **Дом (Household)** — люди дома (родственный статус), общие задачи с исполнителем.
6. **Настройки** — разрешение на уведомления, резервная копия (сохранить/восстановить), удаление
   всех данных, версия приложения.

Источник правды по стилям — `apps/app/src/styles/app.css` (CSS-токены и компонентные классы).

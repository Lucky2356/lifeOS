# Политика конфиденциальности Life OS

_Дата последнего обновления: 19 августа 2026 г._

Коротко: Life OS работает только на вашем устройстве. У приложения нет сервера, аккаунтов и
аналитики — ваши данные физически некуда отправить.

## 1. Кто обрабатывает данные

Вы сами. Приложение не подключается ни к какому серверу и не передаёт данные разработчику: такого
сервера просто не существует. Разработчик не имеет доступа к вашим данным ни при каких условиях.

## 2. Какие данные обрабатываются и где хранятся

Всё, что вы вносите — объекты реестра (документы, вещи, страховки, записи о здоровье), приложенные
файлы и сканы, домашние задачи и люди, решения, прогресс по плейбукам — хранится в локальном
хранилище приложения (IndexedDB) на вашем устройстве.

Приложение **не** собирает: аналитику, статистику использования, рекламные идентификаторы,
местоположение, контакты, историю действий вне приложения. Трекеров нет.

Аккаунта тоже нет — а значит, нет ни e-mail, ни пароля, ни данных для входа.

## 3. Выход в сеть

Приложение обращается в интернет ровно в одном случае: проверка новой версии самого приложения на
GitHub (`github.com`). Запрос содержит только то, что нужно, чтобы скачать файл манифеста; ваши
данные в нём не передаются.

Если устройство офлайн, приложение работает полностью — просто не узнает об обновлении.

## 4. Искусственный интеллект

Его нет. В версиях до 1.0 существовали опциональные ИИ-подсказки через сервер; вместе с сервером они
удалены. Ни один текст никуда не отправляется.

## 5. Передача третьим лицам

Не происходит. Никакой передачи, продажи или обмена данными — их некуда передавать.

Единственный случай, когда данные покидают приложение, — когда вы сами создаёте резервную копию и
сохраняете её файл. Что дальше происходит с этим файлом, решаете вы.

## 6. Ваши права

- **Посмотреть все данные** — они и так у вас, в приложении.
- **Экспорт** — Настройки → «Сохранить копию всех данных»: один файл со всем содержимым, включая
  приложенные документы.
- **Удаление** — Настройки → «Удалить все данные», либо удаление приложения. Данные удаляются с
  устройства; запрашивать удаление у кого-то не нужно.

## 7. Хранение и безопасность

Данные живут, пока установлено приложение. Их защищает то же, что защищает само устройство: учётная
запись ОС, блокировка экрана и шифрование диска. Приложение не добавляет своего пароля — без сервера
любой локальный ключ шифрования пришлось бы держать рядом с данными, и это была бы защита только на
вид. Подробнее о модели угроз — [SECURITY.md](SECURITY.md).

Системный авто-бэкап Android для приложения отключён, чтобы данные не попадали в облако вопреки
сказанному выше.

**Важно:** единственная копия данных — на устройстве. Потеря, поломка или сброс устройства означают
потерю данных. Делайте резервную копию и храните файл там, где храните документы.

## 8. Дети

Приложение не предназначено для самостоятельного использования детьми младшего возраста. Родитель
может добавить ребёнка в список людей дома под свою ответственность — это просто имя в справочнике,
у ребёнка не появляется ни аккаунта, ни доступа.

## 9. Изменения политики

Актуальная версия публикуется в репозитории. Существенные изменения отражаются в дате вверху.

## 10. Контакты

Вопросы и замечания — через issue в [репозитории проекта](https://github.com/Lucky2356/lifeOS).
Оператором своих данных являетесь вы сами.

# ADR 0005 — ИИ как опциональный слой

- Статус: **Принято**
- Дата: 2026-07-04

## Контекст
Продуктовый принцип: **ИИ — опциональный ассистент поверх системы, а не её фундамент.** Любая функция
работает без ИИ. ИИ включается/выключается глобально и по модулям. Ни одна критическая функция
(сохранение данных, напоминания, доступ к документам) не ломается и не деградирует при выключенном ИИ.

## Решение
ИИ реализуется как **отдельный необязательный модуль-слой с портами и инверсией зависимости**:

- **Core не зависит от AI.** Зависимость направлена наоборот: AI-модуль подписывается на явные
  «точки расширения» (suggestion points), которые core предоставляет, но не требует.
- **Только по явному действию пользователя.** ИИ не вызывается фоново/автоматически на core-путях.
  Пользователь нажимает «предложить», «помочь заполнить», «подсказать шаг» — тогда идёт вызов.
- **Provider-agnostic интерфейс.** Абстракция `AiProvider` (методы вроде `suggest`, `summarize`,
  `classify`). Реализации: `NoopProvider` (заглушка, если ИИ выключен/недоступен) и `ClaudeProvider`
  (Claude API, `claude-opus-4-8` / актуальная модель) как рекомендуемый дефолт. Провайдер подключается
  конфигом, не хардкодом.
- **Флаги:** глобальный тумблер ИИ + тумблер на каждый модуль (Ledger/Household/Decision/Bureaucracy/
  Crisis). Выключенный тумблер → соответствующий вызов возвращает «ИИ недоступен», UI показывает ручной путь.
- **Каждое ИИ-предложение помечено** в UI («предложил ИИ») и всегда имеет ручную альтернативу и способ
  отклонить/сделать вручную.
- **Данные:** запрос к внешнему провайдеру = отправка данных наружу. Отправляется только явно
  затронутый минимум, с предупреждением пользователю; чувствительные категории (медицина, документы,
  удостоверения) не отправляются без отдельного явного согласия. По умолчанию — консервативно.

## Обоснование
- Инверсия зависимости гарантирует, что удаление/отключение AI-модуля не ломает core (проверяемо тестом:
  прогон всех критичных сценариев с `NoopProvider`).
- Provider-agnostic слой не запирает на вендора и позволяет локальные модели позже.

## Последствия
- В CI — тест «все критичные пути зелёные при выключенном ИИ» как гейт принципа.
- Настройки приватности ИИ (что можно отправлять) — часть модели пользователя.
